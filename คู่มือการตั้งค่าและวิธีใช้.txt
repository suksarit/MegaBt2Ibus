======================================================================
TN Mower Control System
MegaBt2Ibus
คู่มือการติดตั้ง การต่อสาย และการใช้งาน (THAI)
อ้างอิงตามโค้ดจริงปัจจุบัน
======================================================================

ระบบนี้ใช้:
- Arduino Mega 2560
- FlySky IBUS
- BTS7960
- Servo คันเร่ง
- Relay ควบคุมเปิดปิดเครื่องยนต์
- Relay สตาร์ตเครื่องยนต์
- Relay ไฟส่องสว่าง

Architecture:
- Non-blocking
- Deterministic loop
- ARM / DISARM
- FAILSAFE latch
- Differential drive
- Soft start / stop

IMPORTANT:
- ระบบนี้ยังเป็น Open-loop
- ไม่มี encoder feedback
- ไม่มี current limiting
- ไม่มี hardware emergency stop
- ต้องมีผู้ควบคุมตลอดเวลา

======================================================================
1. REQUIRED HARDWARE
======================================================================

[Controller]
- Arduino Mega 2560

[RC System]
- FlySky i6X
- FlySky Receiver ที่รองรับ IBUS
  เช่น FS-iA6B

[Motor Driver]
- BTS7960 จำนวน 4 Channel
  (2 บอร์ดแบบ Dual หรือ 4 บอร์ดเดี่ยว)

[Drive Motors]
- มอเตอร์ DC ซ้ายหน้า

- มอเตอร์ DC ขวาหน้า
- มอเตอร์ DC ขวาหลัง

[Engine Control]
- Servo คันเร่ง
- Ignition Relay
- Starter Relay

[Auxiliary]
- Light Relay

[Power]
- Battery สำหรับมอเตอร์
- DC-DC สำหรับ Arduino
- Separate power supply สำหรับ Servo

======================================================================
2. IMPORTANT POWER RULES
======================================================================

IMPORTANT:
- GND ทุกระบบต้องต่อร่วมกัน

ห้าม:
- จ่าย Servo จาก 5V Arduino โดยตรง
- ใช้ไฟมอเตอร์ร่วมกับ Arduino โดยไม่มี DC-DC
- เดินสาย IBUS ขนานกับสายมอเตอร์กำลัง

แนะนำ:
- ใช้ DC-DC แยกสำหรับ Logic
- ใช้ fuse ทุกระบบ
- ติด heatsink BTS7960
- ใช้สายไฟขนาดเหมาะสม
- ติด emergency stop จริงแบบ hardware

======================================================================
3. SYSTEM STATE
======================================================================

[STATE_DISARMED]
- ระบบยังไม่ ARM
- มอเตอร์หยุด
- เครื่องยนต์ดับ
- Relay OFF

[STATE_ACTIVE]
- ระบบพร้อมขับเคลื่อน
- มอเตอร์ทำงานได้
- เครื่องยนต์ควบคุมได้

[STATE_FAILSAFE]
- เกิดสัญญาณผิดปกติ
- ระบบสั่งหยุด actuator
- ต้อง DISARM ก่อนกลับมาใช้งาน

======================================================================
4. FLYSKY CHANNEL MAPPING
======================================================================

CH1 = Steering
CH2 = Drive Throttle
CH3 = Engine Throttle Servo
CH4 = Reserved
CH5 = ARM / DISARM
CH6 = Ignition
CH7 = Starter
CH8 = Light Relay

Logic:
- ค่า > 1500 = ON
- ค่า < 1500 = OFF

แนะนำ Switch:
- CH5 → SWA
- CH6 → SWB
- CH7 → SWC
- CH8 → SWD

Stick Mode:
- Mode 2

*สามารถเปลี่ยนแปลงการควบคุมช่องสัญญานได้ที่ config.h และปรับตั้งค่าที่รีโมท

======================================================================
5. RECEIVER → ARDUINO WIRING
======================================================================

[IBUS Receiver]

IBUS → RX1 (Pin 19)
VCC  → 5V
GND  → GND

IMPORTANT:
- ใช้ Serial1 เท่านั้น
- ห้ามใช้ RX0/TX0
- RX0/TX0 ใช้สำหรับ USB Serial

8. POWER WIRING RECOMMENDATION
======================================================================

[Motor Power]

- GND ต้อง common
- ใช้ capacitor ใกล้ Arduino
- ใช้ fuse ทุก supply line

======================================================================
9. SYSTEM BOOT SEQUENCE
======================================================================

ลำดับที่ถูกต้อง:

1. เปิดรีโมท FlySky
2. ตรวจสอบว่า ARM = OFF
3. เปิดระบบ 
4. รอ Receiver เชื่อมต่อ
5. FAILSAFE ถูกปลด
6. ระบบอยู่ STATE_DISARMED
7. ARM ระบบ
8. เริ่มใช้งาน

======================================================================
10. ARM / DISARM
======================================================================

ARM:
- CH5 > 1500
- STATE → ACTIVE

DISARM:
- CH5 < 1500
- STATE → DISARMED

เมื่อ DISARM:
- มอเตอร์หยุดแบบ soft stop
- เครื่องยนต์ดับ
- Relay OFF

======================================================================
11. DRIVE CONTROL
======================================================================

Stick ขวา:

ขึ้น/ลง:
- เดินหน้า / ถอยหลัง

ซ้าย/ขวา:
- เลี้ยว

ระบบรองรับ:
- Differential drive
- Deadzone
- Soft start
- Soft stop
- Direction reversal protection
- Slew limiting

IMPORTANT:
- ไม่มี speed feedback
- ไม่มี traction control
- ไม่มี current limiting

======================================================================
12. ENGINE CONTROL
======================================================================

ลำดับการสตาร์ต:

1. ARM ระบบ
2. CH6 ON (Ignition)
3. กด CH7 (Starter)
4. ไม่ควรกดเกิน 2.5 วินาที
5. ปล่อย Starter
6. ใช้ CH3 ควบคุมคันเร่ง

IMPORTANT:
- ยังไม่มี RPM sensor
- ระบบยังไม่รู้ว่าเครื่องติดจริงหรือไม่
- RUNNING state ยังเป็น logic-only

======================================================================
13. LIGHT CONTROL
======================================================================

CH8 ON
→ Light Relay ON

CH8 OFF
→ Light Relay OFF

FAILSAFE:
→ Light Relay OFF

======================================================================
14. FAILSAFE SYSTEM
======================================================================

FAILSAFE จะเกิดเมื่อ:

- รีโมทปิด
- Receiver ดับ
- IBUS timeout
- สัญญาณผิดปกติต่อเนื่อง

เมื่อ FAILSAFE:

- ระบบสั่งหยุดมอเตอร์
- Disable BTS7960
- Ignition OFF
- Starter OFF
- Relay OFF

IMPORTANT:
- เป็น software failsafe
- ยังไม่ใช่ hardware power cutoff

======================================================================
15. FAILSAFE RECOVERY
======================================================================

ระบบจะไม่ recover เองอัตโนมัติ

ต้อง:

1. แก้ปัญหาสัญญาณ
2. ปิด ARM
3. รอ signal stable
4. ARM ใหม่

======================================================================
16. BUILT-IN PROTECTION
======================================================================

มี:
- IBUS validation
- FAILSAFE latch
- Soft stop
- Servo slew limiter
- Deadzone
- Direction reversal protection
- Watchdog timer
- Starter timeout

ยังไม่มี:
- Encoder feedback
- Current sensor protection
- Thermal protection
- Brownout protection
- Hardware E-stop
- Closed-loop speed control

======================================================================
17. IMPORTANT LIMITATIONS
======================================================================

ระบบนี้:
- ยังเป็น Open-loop
- ไม่มี obstacle avoidance
- ไม่มี autonomous navigation
- ไม่มี motor feedback
- ไม่มี relay feedback
- ไม่มี actuator watchdog

IMPORTANT:
- ห้ามปล่อยรถทำงานโดยไม่มีผู้ควบคุม
- ต้องมี emergency stop จริงเสมอ
- ต้องทดสอบบนล้อยกก่อนลงพื้นจริง

======================================================================
18. EMI / NOISE WARNING
======================================================================

ระบบมอเตอร์กำลังสูงอาจเกิด:
- EMI
- Voltage spike
- Brownout
- Power transient

อาการที่อาจเกิด:
- Arduino reboot
- Servo jitter
- IBUS หลุด
- Receiver reset

แนะนำ:
- แยกสาย signal กับ power
- ใช้ twisted pair
- ใช้ capacitor
- ใช้ ferrite bead
- ติด TVS diode
- เดิน ground แบบ star grounding

======================================================================
19. THERMAL WARNING
======================================================================

BTS7960 และมอเตอร์อาจร้อนมากเมื่อ:
- หญ้าหนา
- ล้อติด
- โหลดหนัก
- ใช้งานต่อเนื่อง

ต้อง:
- ติด heatsink
- มี airflow
- ตรวจสอบอุณหภูมิจริง
