คู่มือการตั้งค่า การต่อสาย และการใช้งาน
ระบบควบคุมรถ TN Mower (MegaBt2Ibus) [ภาษาไทย]
======================================================================

ระบบนี้ใช้ Arduino Mega 2560 รับสัญญาณ FlySky IBUS
ควบคุมมอเตอร์ผ่าน BTS7960 และควบคุมเครื่องยนต์ด้วย Servo และ Relay
มีระบบ ARM / DISARM / FAILSAFE ทำงานตรงตามโค้ดจริง

======================================================================
1. อุปกรณ์ที่ต้องใช้
======================================================================

- Arduino Mega 2560
- รีโมท FlySky i6X
- รีซีฟเวอร์ FlySky ที่รองรับ IBUS (เช่น FS-iA6B)
- BTS7960 จำนวน 2 ตัว (ซ้าย / ขวา)
- มอเตอร์ DC ซ้าย / ขวา
- Servo คันเร่งเครื่องยนต์
- Relay:
  - Ignition
  - Starter
  - Light
- แหล่งจ่ายไฟ:
  - มอเตอร์
  - Servo
  - Logic (Arduino)

ข้อสำคัญ:
- GND ทุกระบบต้องต่อร่วมกัน
- ห้ามจ่ายไฟ Servo จากขา 5V ของ Arduino โดยตรง

======================================================================
2. การตั้งค่ารีโมท FlySky i6X
======================================================================

โหมด:
- Stick Mode: Mode 2

การกำหนด Channel:

CH1 : Stick ขวา ซ้าย/ขวา   → เลี้ยวรถ
CH2 : Stick ขวา ขึ้น/ลง    → เดินหน้า / ถอยหลัง
CH3 : Stick ซ้าย ขึ้น/ลง   → คันเร่งเครื่องยนต์ (Servo)
CH4 : ไม่ใช้
CH5 : Switch               → ARM / DISARM
CH6 : Switch               → Ignition ON / OFF
CH7 : Switch               → Starter
CH8 : Switch               → ไฟ / รีเลย์เสริม

เงื่อนไขในโค้ด:
- ค่า > 1500 = ON
- ค่า < 1500 = OFF

แนะนำ Switch:
- CH5 → SWA
- CH6 → SWB
- CH7 → SWC
- CH8 → SWD

======================================================================
3. การต่อ Receiver → Arduino Mega
======================================================================

IBUS  → RX1 (Pin 19)
VCC   → 5V
GND   → GND

ข้อควรระวัง:
- ใช้ Serial1 เท่านั้น
- ห้ามต่อ IBUS เข้าขา RX0 / TX0

======================================================================
4. การต่อระบบขับเคลื่อน (BTS7960)
======================================================================

มอเตอร์ซ้าย:
- EN    → Pin 4
- LPWM  → Pin 6
- RPWM  → Pin 5

มอเตอร์ขวา:
- EN    → Pin 9
- LPWM  → Pin 8
- RPWM  → Pin 7

ไฟมอเตอร์:
- ใช้แหล่งจ่ายไฟแยก
- GND ต้องร่วมกับ Arduino

======================================================================
5. การต่อระบบเครื่องยนต์
======================================================================

Servo คันเร่ง:
- Signal → Pin 9
- VCC    → 5–6V (แหล่งจ่ายแยก)
- GND    → GND

Relay:
- Ignition Relay → Pin 22
- Starter Relay  → Pin 23
- Light Relay    → Pin 24

======================================================================
6. ลำดับการทำงานของระบบ
======================================================================

เริ่มต้น:
- เปิด Arduino
- เปิดรีโมท

สถานะเริ่มต้น:
- FAILSAFE = ON
- STATE = DISARMED
- มอเตอร์หยุด
- เครื่องยนต์ดับ
- รีเลย์ทั้งหมด OFF

ปลด FAILSAFE:
- ปิด ARM (CH5 OFF)
- IBUS ต้องนิ่งต่อเนื่อง
- FAILSAFE ถูกปลด
- STATE ยังเป็น DISARMED

ARM ระบบ:
- CH5 ON
- STATE → ACTIVE
- พร้อมใช้งาน

======================================================================
7. การขับเคลื่อนรถ
======================================================================

Stick ขวา:
- ขึ้น/ลง   → เดินหน้า / ถอยหลัง
- ซ้าย/ขวา → เลี้ยว

คุณสมบัติ:
- Deadzone
- Soft start / stop
- ป้องกันการกลับทิศทันที
- FAILSAFE ตัด BTS7960 ทันที

======================================================================
8. การสตาร์ตเครื่องยนต์
======================================================================

ลำดับที่ถูกต้อง:
1) ARM (CH5 ON)
2) Ignition ON (CH6 ON)
3) กด Starter (CH7) ไม่เกิน 2.5 วินาที
4) ปล่อย Starter
5) ควบคุมคันเร่งด้วย CH3

หมายเหตุ:
- ไม่มีเซ็นเซอร์ตรวจว่าเครื่องติดจริง
- ถือว่า RUNNING เมื่อ Ignition ยัง ON

======================================================================
9. รีเลย์ไฟ
======================================================================

CH8 ON  → ไฟติด
CH8 OFF → ไฟดับ

FAILSAFE:
- ไฟถูกปิดทันที

======================================================================
10. FAILSAFE
======================================================================

เกิดเมื่อ:
- รีโมทปิด
- IBUS หาย
- สัญญาณเสียต่อเนื่อง

ผลลัพธ์ภายใน ~150–500 ms:
- มอเตอร์หยุด
- Ignition OFF
- Starter OFF
- รีเลย์ทั้งหมด OFF

การกู้คืน:
- ต้อง DISARM
- แล้ว ARM ใหม่
- ระบบไม่กลับมาทำงานเอง

======================================================================
11. ข้อจำกัดของระบบ
======================================================================

- ไม่มี sensor feedback
- ไม่มี current limit
- ไม่มี engine RPM detect
- เป็นระบบ open-loop
- ต้องมีผู้ควบคุมตลอดเวลา

Arduino Mega 2560 Pin Map
======================================================================

[IBUS]
RX1 (19) → Receiver IBUS

[Drive - BTS7960]
Motor Left:
  EN    → Pin 4
  LPWM  → Pin 6
  RPWM  → Pin 5

Motor Right:
  EN    → Pin 9
  LPWM  → Pin 8
  RPWM  → Pin 7

[Engine]
Throttle Servo → Pin 9
Ignition Relay → Pin 22
Starter Relay  → Pin 23

[Auxiliary]
Light Relay    → Pin 24

TN Mower Control System (MegaBt2Ibus) – ENGLISH
======================================================================

This document provides setup, wiring, and operation instructions
for the TN Mower control system based on Arduino Mega 2560
using FlySky IBUS remote control.

======================================================================
1. Required Hardware
======================================================================

- Arduino Mega 2560
- FlySky i6X Transmitter
- FlySky IBUS Receiver (FS-iA6B or compatible)
- BTS7960 Motor Driver x2
- DC Motors (Left / Right)
- Throttle Servo
- Relays: Ignition, Starter, Light
- Separate power supplies for motor, servo, and logic

IMPORTANT:
- All grounds must be common
- Do NOT power servo from Arduino 5V pin

======================================================================
2. FlySky i6X Configuration
======================================================================

- Stick Mode: Mode 2

Channel Assignment:

CH1 : Steering
CH2 : Drive Throttle
CH3 : Engine Throttle Servo
CH4 : Not Used
CH5 : ARM / DISARM
CH6 : Ignition
CH7 : Starter
CH8 : Light Relay

Logic:
- Value > 1500 = ON
- Value < 1500 = OFF

======================================================================
3. Receiver Wiring
======================================================================

IBUS → RX1 (Pin 19)
VCC  → 5V
GND  → GND

Use Serial1 only.

======================================================================
4. FAILSAFE Summary
======================================================================

If IBUS is lost:
- Motors stop immediately
- Engine shuts down
- All relays turn OFF

System requires DISARM then ARM to resume.
Automatic recovery is NOT allowed.
