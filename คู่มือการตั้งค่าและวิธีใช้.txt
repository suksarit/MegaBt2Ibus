คู่มือการตั้งค่ารีโมท การต่อสาย และวิธีใช้งาน
ระบบควบคุมรถ TN Mower (MegaBt2Ibus)
=====================================================

ระบบนี้ใช้ Arduino Mega 2560 รับสัญญาณ FlySky IBUS
ควบคุมมอเตอร์ผ่าน BTS7960 และควบคุมเครื่องยนต์ด้วย Servo + Relay
มีระบบ ARM / DISARM / FAILSAFE ตามโค้ดจริง

-----------------------------------------------------
1. อุปกรณ์ที่ต้องใช้
-----------------------------------------------------

1) Arduino Mega 2560
2) รีโมท FlySky i6X
3) Receiver FlySky ที่รองรับ IBUS (เช่น FS-iA6B)
4) BTS7960 จำนวน 2 ตัว (ซ้าย / ขวา)
5) มอเตอร์ DC ซ้าย / ขวา
6) Servo คันเร่งเครื่องยนต์
7) Relay:
   - Ignition
   - Starter
   - Light
8) แหล่งจ่ายไฟแยก:
   - มอเตอร์
   - Servo
   - Arduino (Logic)

หมายเหตุ:
- GND ทุกระบบต้องต่อร่วมกัน
- ห้ามจ่าย Servo จากขา 5V ของ Arduino โดยตรง

-----------------------------------------------------
2. การตั้งค่ารีโมท FlySky i6X
-----------------------------------------------------

2.1 โหมดรีโมท
- ใช้ Mode 2

2.2 การกำหนด Channel (สำคัญมาก)

CH1 : Stick ขวา ซ้าย-ขวา  -> เลี้ยวรถ (Steer)
CH2 : Stick ขวา ขึ้น-ลง   -> เดินหน้า / ถอยหลัง
CH3 : Stick ซ้าย ขึ้น-ลง  -> คันเร่งเครื่องยนต์ (Servo)
CH4 : ไม่ใช้
CH5 : Switch               -> ARM / DISARM
CH6 : Switch               -> Ignition ON / OFF
CH7 : Switch               -> Starter
CH8 : Switch               -> ไฟ / รีเลย์เสริม

เงื่อนไขในโค้ด:
- ค่า > 1500 = ON
- ค่า < 1500 = OFF

2.3 แนะนำตำแหน่ง Switch
- CH5 : SWA
- CH6 : SWB
- CH7 : SWC
- CH8 : SWD

-----------------------------------------------------
3. การต่อสาย Receiver → Arduino Mega
-----------------------------------------------------

IBUS  -> RX1 (Pin 19)
VCC   -> 5V
GND   -> GND

ข้อควรระวัง:
- ใช้ Serial1 เท่านั้น
- ห้ามต่อ IBUS เข้าขา RX0 / TX0

-----------------------------------------------------
4. การต่อ Drive (BTS7960)
-----------------------------------------------------

4.1 มอเตอร์ซ้าย
EN    -> Pin 4
LPWM  -> Pin 6
RPWM  -> Pin 5

4.2 มอเตอร์ขวา
EN    -> Pin 9
LPWM  -> Pin 8
RPWM  -> Pin 7

ไฟมอเตอร์:
- ใช้แหล่งจ่ายไฟแยกจาก Arduino
- GND ต้องร่วมกัน

-----------------------------------------------------
5. การต่อระบบเครื่องยนต์
-----------------------------------------------------

5.1 Servo คันเร่ง
Signal -> Pin 9
VCC    -> 5–6V (แหล่งจ่ายแยก)
GND    -> GND

5.2 Relay
Ignition Relay -> Pin 22
Starter Relay  -> Pin 23
Light Relay    -> Pin 24

-----------------------------------------------------
6. ลำดับการทำงานของระบบ (ตามโค้ดจริง)
-----------------------------------------------------

6.1 เปิดระบบ
- เปิด Arduino
- เปิดรีโมท

สถานะเริ่มต้น:
- FAILSAFE = ON
- STATE = DISARMED
- มอเตอร์หยุด
- เครื่องยนต์ดับ
- รีเลย์ทั้งหมด OFF

6.2 เมื่อ IBUS มา
- ระบบตรวจสอบสัญญาณ IBUS ต่อเนื่อง
- ยังไม่ทำงานจนกว่าจะ DISARM

6.3 ปลด FAILSAFE
- ปิด ARM (CH5 OFF)
- IBUS ต้องนิ่งต่อเนื่อง
- FAILSAFE จะถูกปลด
- STATE ยังเป็น DISARMED

6.4 ARM ระบบ
- เปิด ARM (CH5 ON)
- STATE -> ACTIVE
- ระบบพร้อมใช้งาน

-----------------------------------------------------
7. การขับเคลื่อนรถ
-----------------------------------------------------

ใช้ Stick ขวา:
- ขึ้น / ลง  : เดินหน้า / ถอยหลัง
- ซ้าย / ขวา: เลี้ยว

คุณสมบัติจากโค้ด:
- Deadzone กันสั่น
- Soft start / stop
- ห้ามกลับทิศทันที
- FAILSAFE = Disable BTS7960

-----------------------------------------------------
8. การสตาร์ตเครื่องยนต์
-----------------------------------------------------

ลำดับที่ถูกต้อง (ห้ามสลับ):

1) ARM (CH5 ON)
2) Ignition ON (CH6 ON)
3) กด Starter (CH7)
   - สตาร์ตได้สูงสุด 2.5 วินาที
   - กันการกดซ้ำ
4) ปล่อย Starter
5) คุมคันเร่งด้วย Stick ซ้าย (CH3)

หมายเหตุสำคัญ:
- ระบบไม่มี sensor ตรวจว่าเครื่องติดจริง
- RUNNING = Ignition ยัง ON หลังสตาร์ต

-----------------------------------------------------
9. รีเลย์ไฟ
-----------------------------------------------------

CH8 ON  -> ไฟติด
CH8 OFF -> ไฟดับ

FAILSAFE:
- รีเลย์ไฟถูกปิดทันที

-----------------------------------------------------
10. กรณีฉุกเฉิน (FAILSAFE)
-----------------------------------------------------

เหตุการณ์:
- รีโมทปิด
- สัญญาณ IBUS หาย
- สัญญาณเสียหายต่อเนื่อง

ภายในเวลาประมาณ 150–500 ms:
- มอเตอร์หยุดทันที
- BTS7960 Disable
- Ignition OFF
- Starter OFF
- รีเลย์ทั้งหมด OFF

เมื่อ IBUS กลับมา:
- ระบบยังอยู่ FAILSAFE
- ต้อง:
  1) ปิด ARM
  2) เปิด ARM ใหม่

รถจะไม่กลับมาทำงานเองเด็ดขาด

-----------------------------------------------------
11. ข้อจำกัดของระบบ (ต้องทราบ)
-----------------------------------------------------

- ไม่มี sensor feedback ใด ๆ
- ไม่มี current limit
- ไม่มี engine running detect
- ไม่ควรปล่อยทำงานโดยไม่มีผู้ควบคุม

-----------------------------------------------------
สรุป
-----------------------------------------------------

รีโมท = ตัวส่งคำสั่ง
การตัดสินใจจริง = โค้ด

ถ้าไม่ ARM -> รถไม่ทำงาน
ถ้า IBUS หาย -> ทุกอย่างดับทันที

Arduino Mega 2560 Pin Map
-----------------------------------------------------

[IBUS]
RX1 (19)  -> Receiver IBUS

[Drive - BTS7960]
Motor Left:
  EN    -> Pin 4
  LPWM  -> Pin 6
  RPWM  -> Pin 5

Motor Right:
  EN    -> Pin 9
  LPWM  -> Pin 8
  RPWM  -> Pin 7

[Engine]
Throttle Servo Signal -> Pin 9
Ignition Relay        -> Pin 22
Starter Relay         -> Pin 23

[Auxiliary]
Light Relay           -> Pin 24

[Power]
5V / GND              -> Logic / Receiver
External Supply       -> Motor / Servo

=====================================================
รายการไลบรารีที่ต้องติดตั้งใน Arduino IDE
โครงการ TN Mower (MegaBt2Ibus)
=====================================================

ระบบนี้ใช้ Arduino Mega 2560
อ้างอิงจากโค้ดล่าสุดทั้งหมดที่ใช้งานจริง
ไม่มีไลบรารีแฝง ไม่มี dependency ซ้อน

-----------------------------------------------------
1. Arduino AVR Core (มีมาให้แล้ว)
-----------------------------------------------------

ชื่อ:
- Arduino AVR Core

ผู้พัฒนา:
- Arduino

ใช้ในโค้ด:
#include <Arduino.h>
#include <avr/wdt.h>

หน้าที่:
- ฟังก์ชันพื้นฐานทั้งหมด (pinMode, digitalWrite, millis, map, constrain ฯลฯ)
- Watchdog Timer

การติดตั้ง:
- ไม่ต้องติดตั้งเพิ่ม
- มาพร้อม Arduino IDE

เงื่อนไข:
- ต้องเลือก Board เป็น "Arduino Mega 2560"

-----------------------------------------------------
2. Servo Library (มีมาให้แล้ว)
-----------------------------------------------------

ชื่อ:
- Servo

ผู้พัฒนา:
- Arduino

ใช้ในโค้ด:
#include <Servo.h>

หน้าที่:
- ควบคุม Servo คันเร่งเครื่องยนต์

การติดตั้ง:
- ไม่ต้องติดตั้งเพิ่ม
- มาพร้อม Arduino IDE

-----------------------------------------------------
3. IBusBM (FlySky IBUS Library)
-----------------------------------------------------

ชื่อ:
- IBusBM

ผู้พัฒนา:
- bmellink

แหล่งดาวน์โหลด (ทางการ):
- https://github.com/bmellink/IBusBM

ใช้ในโค้ด:
#include <IBusBM.h>

หน้าที่:
- รับสัญญาณ FlySky IBUS ผ่าน Serial
- อ่านค่า Channel CH1–CH10
- ทำงานแบบ non-blocking

วิธีติดตั้ง:
Arduino IDE →
Sketch →
Include Library →
Manage Libraries →
ค้นหา "IBusBM" →
ติดตั้ง "IBusBM by bmellink"

หรือ:
Sketch →
Include Library →
Add .ZIP Library →
เลือกไฟล์ ZIP ที่ดาวน์โหลดจาก GitHub

-----------------------------------------------------
4. BTS7960 Motor Driver Library
-----------------------------------------------------

ชื่อ:
- BTS7960

ผู้พัฒนา:
- Community (Rob Tillaart)

แหล่งดาวน์โหลดที่ API ตรงกับโค้ด:
- https://github.com/RobTillaart/BTS7960

ใช้ในโค้ด:
#include <BTS7960.h>

ฟังก์ชันที่โค้ดใช้งานจริง:
- Enable()
- Disable()
- TurnLeft()
- TurnRight()
- Stop()

ข้อสำคัญ:
- ต้องเป็นไลบรารีที่ใช้ชื่อฟังก์ชันตัวพิมพ์ใหญ่ตามนี้
- ถ้าใช้ไลบรารี BTS7960 คนละตัว จะคอมไพล์ไม่ผ่าน

วิธีติดตั้ง:
- ดาวน์โหลด ZIP จาก GitHub
- Arduino IDE →
  Sketch →
  Include Library →
  Add .ZIP Library

# TN Mower – MegaBt2Ibus Control System

ระบบควบคุมรถ/เครื่องจักรด้วยรีโมท FlySky ผ่านสัญญาณ IBUS
พัฒนาบน Arduino Mega 2560
ออกแบบเน้นความปลอดภัย (ARM / DISARM / FAILSAFE) และการทำงานแบบ non-blocking

โค้ดชุดนี้เหมาะสำหรับงานทดลอง งานพัฒนา และงานควบคุมที่มีผู้ใช้งานดูแลตลอดเวลา

## Features
- FlySky i6X + IBUS รองรับ 10 Channels
- ARM / DISARM ชัดเจน
- FAILSAFE แบบ LATCH (IBUS หาย = ดับทันที)
- Tank Drive ด้วย BTS7960
- Soft start / soft stop
- ป้องกันการกลับทิศทันที
- ควบคุมเครื่องยนต์ด้วย Throttle Servo + Ignition/Starter Relay
- Starter timeout และ lock
- รีเลย์เสริม (ไฟ)
- Watchdog Timer
- โครงสร้างแยก Manager ชัดเจน

## System Concept
รีโมทเป็นเพียง input
การตัดสินใจทั้งหมดอยู่ที่โค้ด

Flow:
FlySky Remote
→ IBusManager
→ SafetyManager
→ SystemState
→ Drive / Engine / Relay

เมื่อ FAILSAFE ทำงาน ทุก subsystem จะถูกตัดทันที และไม่กลับมาเอง

## Channel Mapping (FlySky i6X)
CH1  : Steer
CH2  : Drive Throttle
CH3  : Engine Throttle Servo
CH4  : Not Used
CH5  : ARM / DISARM
CH6  : Ignition
CH7  : Starter
CH8  : Light Relay
CH9  : Reserve
CH10 : Reserve

Condition:
- Value > 1500 = ON
- Value < 1500 = OFF

## Pin Map (Arduino Mega 2560)

IBUS
- Receiver IBUS → RX1 (Pin 19)

Drive – BTS7960
Motor Left:
- EN   → Pin 4
- LPWM → Pin 6
- RPWM → Pin 5

Motor Right:
- EN   → Pin 9
- LPWM → Pin 8
- RPWM → Pin 7

Engine
- Throttle Servo Signal → Pin 9
- Ignition Relay        → Pin 22
- Starter Relay         → Pin 23

Auxiliary
- Light Relay           → Pin 24

## Quick Start
1. Power on transmitter
2. Power on system
3. Set CH5 = OFF (DISARM) to clear FAILSAFE
4. Set CH5 = ON (ARM)
5. Operate drive and engine via assigned channels

## FAILSAFE Behavior
Triggered when:
- Transmitter off
- IBUS signal lost
- Persistent signal error

Action:
- Motors stop
- BTS7960 disabled
- Ignition OFF
- Starter OFF
- All relays OFF

Recovery:
- DISARM required
- ARM again to resume
- System never resumes automatically

## Limitations
- No sensor feedback
- No current limit
- No engine running detection
- Open-loop system
- Must be supervised at all times

## Intended Use
Suitable for:
- Prototype development
- Field testing
- Supervised remote control systems

Not suitable for:
- Commercial deployment
- Unattended autonomous operation
